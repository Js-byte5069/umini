# EDEN 伊甸星 — 第一人称雪原科幻环境(垂直切片)

three.js(已本地 vendor,无需 CDN)。静态页面,任意静态服务器即可:

```bash
cd eden && python3 -m http.server 8123   # 打开 http://localhost:8123
```

操作:WASD 移动 · Shift 奔跑 · 空格 跳跃 · 鼠标视角(点击进入,Esc 释放)。
URL 参数(`?sparse=2.0` 地面残骸间距倍数,越大越空;渲染调试:`?nopost` 关闭整条后处理、`?nopaint` 只关闭绘画感平滑/分带、`?tdbg=1|2` 地形着色器调试视图):
`?q=low` 低画质(2K 阴影、1x 像素比);`?noao` 关闭环境光遮蔽;`?norocks` 使用代码生成岩石;`?cam=x,z,yaw°,pitch°[,y]` 调试机位;`?shot` 隐藏 HUD。

## 已完成范围
线性路线:**雪原入口 → 废弃城区 → 雪原峡谷(圆环地标)→ 封闭的工厂大门**
- 入口雪丘 + 可步行的拱形高架桥(楼梯上桥)
- 城区街道:10 栋分层建筑、天桥(桁架)、管线龙门架、可穿行机库(室内外连接/侧路)、掩体与废墟拱门
- 峡谷:台地岩壁、大型雕刻岩体、巨型圆环、倒塌巨板、工厂大门

**未完成(规划中)**:地下设施、高地与环带观景台、特殊遗迹区(倒塌巨构区)。

## Blender 资产管线(`tools/`)
需要 `pip install bpy==4.2.0`,无头运行,确定性输出到 `assets/`。资产缺失时游戏自动回退到代码生成版本。
- `gen_buildings.py [id]`(每栋街区建筑只有**一整块**珊瑚红大板 + 深色衬框,由 `buildings.json` 的 `accent` 控制;立面嵌板底面一律为深石板色,不再散落小块珊瑚红) → `buildings.glb`(约 6MB,15 栋、3 级 LOD)。由 `tools/buildings.json` 驱动(同时生成 `assets/buildings.json` 与 `src/fallback_specs.js`),该规格也决定游戏里的摆放、碰撞与屋顶积雪。嵌板/竖缝窗是网格里真实的凹陷,倒角圆边,烘焙 AO。
- `gen_towers.py` → `towers.glb` + `towers.json`(约 2.9MB):按参考图做的"前文明哨塔"主角建筑,2 座(id 20/21,39×34×112 m 与 32.5×30×96 m)。深色基础块配浅色门框;封闭环形观测廊(连续栏杆、深色板岩檐口、下环梁、粗壮的浅/深色外侧桥墩);浅色整块塔身(窗洞和缝窗大幅精简,无描边),正面一条通高深色槽里嵌一块宽珊瑚门板(上下两块,一道横缝);深板岩色脊柱立柱高低错落,两条珊瑚细边;塔冠是深色基座上一根高大的浅色针塔(带细桅杆)、一个偏心的平顶板岩块(第二块珊瑚板)和一个更矮的浅色塔块,三者不同轴不同高,最高的深色立柱站在针塔后面;分层岩石基座(后侧、两翼和入口旁一块前岩:灰紫/板岩蓝岩层夹一条珊瑚岩带,新增 `rockMauve` 材质,阶梯式雪帽)和每层台阶上的连续积雪;塔后各有两块倾斜、顶部断裂的倒塌石板(带碰撞体和雪脚),两座塔的尖塔/高柱偏向相反一侧,不再对称。桥口下方是浅色阶梯托架。`world.js` 的 `bld()` 对塔用全部碰撞盒的外包矩形(含倒塌石板)作散布禁区。每座带一座通向相邻建筑门洞的桁架桥(`towers.json` 的 `bridge` 字段,桥面离地约 20m,为造型连接,不可达),命名与 `buildings.glb` 相同,经同一条加载路径摆放。
- `gen_props.py` → `props.glb`(约 4MB):8 种针塔、8 种倒塌巨板(灰/橙)、集装箱、格构支柱。
- `gen_rocks.py` → `rocks.glb`(约 2.5MB):37 种雕刻岩石(11 种大型主体 + 23 种小岩石:圆石、碎块、倾斜楔形、板岩、多块堆叠)加 12 种碎石,烘焙 AO 与边缘提亮,独立的积雪帽网格,4 级 LOD。由 `src/scatter.js` 成簇摆放(主体+卫星+碎石扇+雪堤)。运行:`PYTHONDONTWRITEBYTECODE=1 python3 tools/gen_rocks.py`(环境变量 `ROCKS_OUT`、`ROCKS_ONLY`)。
- `gen_debris.py` → `debris.glb`(约 3.2MB):25 类残骸/废墟道具(断墙、拱段、倒塌柱鼓、桁架、管道、罐体、齿轮/叶轮、履带残骸、板条箱、路障、碎石扇等,约 56 变体,3 级 LOD),由 `src/dressing.js` 成组摆放。调试参数:`?nodress`、`?fallbackdress`。
- `gen_structures.py` → `structures.glb`(约 5.4MB):拱形高架桥模块、圆环(160 段旋转体)、工厂大门、龙门架、天桥桁架、楼梯、废墟墙、机库。
- 生成脚本里的已知坑:`extrude_face_region` 默认保留原面;圆锥半径方向在旋转后颠倒;烘焙 AO 前必须先细分。
- 上线建议:开启 gzip/brotli(`python http.server` 不压缩,四个 GLB 合计约 21MB,压缩后约 9MB)。

## 技术要点
- 几何:真实凹陷窗洞(双层立面挤出)、圆角倒角、放样(loft)柱体/尖塔、平滑积雪层、软最小值雕刻岩石;无 Cube+Cone 拼接。
- 每个主要结构 LOD0–LOD3(`THREE.LOD`),远处小物体距离剔除;圆环为高细分旋转体。
- 地形:解析高度场(渲染/碰撞/摆放共用),64m 分块 4 级 LOD,法线分级平滑,岩层条纹在着色器中按世界高度绘制。
- 着色:3 阶卡通光照 + 冷色环境光;所有朝上表面自动"手绘积雪";AO 烘焙进顶点色(未使用法线贴图)。
- 优化:同材质合并批次;未使用 GPU instancing 与遮挡剔除(WebGL 无 Nanite)。
- 碰撞:高度场 + AABB,台阶高度 0.62m,坡度限制。

## 渲染与美术层(最终精修)
- `src/atmosphere.js`:全局雾着色器块,做大气透视(远处提亮、降饱和、融进地平线的淡紫蓝雾,随高度变化)。
- `src/sky.js`:渐变天空、大块积云、行星(柔和分带与大气边缘)、细星环、小月亮。
- `src/main.js`:阳光 + 冷蓝环境光的光照、软阴影、GTAO、克制的调色与绘画感后处理(轻度分带、边缘平滑、柔和泛光)。
- `src/materials.js` / `src/terrain_material.js`:建筑、岩石、积雪、悬崖的绘画材质(石板蓝/紫蓝漂移、珊瑚红点缀、冷色阴影、有机雪边)。
- 建筑材质的"厚涂"层(`src/materials.js` 的 `uDetail`/`uUnder`,仅用于 wall/wallLight/wallDark/trim/metal/accent/accentDark/deck):墙面对齐的细胞状色块(每块是一个偏暖或偏冷的平涂色阶,边缘略有抖动,色阶交界留一丝笔触堆出的亮脊)、每块板内上亮下暗的渐变、清晰的板缝加亮边、仅沿倒角出现的边缘磨损、用法线屏幕导数(`fwidth(vWN)`)得到的倒角亮边。没有颗粒、水渍或大面积掉漆(第一版做成了迷彩斑点,已撤掉)。全部是 ALU,无贴图,随距离淡出,雪面不受影响。最终画面处理(`src/main.js` finalPass)新增三道笔触:`kuw`(4 扇区 Kuwahara 近似,把色块内的低对比起伏抹成一笔,高对比边缘和细线保留)、`brush`(沿形体结构切线的范围加权涂抹)、`imp`(沿流向的笔触高度场,从左上打光,得到一层薄薄的厚涂浮雕);均可用 URL 参数调节或关闭(`&kuw=0&brush=0&imp=0`),`?q=low` 默认关闭。珊瑚色在阴影里保持暖红,不再偏洋红。`tools/gen_buildings.py` 的 `BEV_K/BEV_ADD` 放大盒体倒角(×1.8+0.04),`gen_towers.py` 的塔体倒角 0.2 m / 2 段。已知未解决:形体仍是规整方块;概念图以深板岩为主色、阴影形状更硬、对比更强,我们仍偏浅偏雾;笔触是屏幕空间的,镜头移动时会有轻微"纱窗"感;未在真实显卡上测过后处理的耗时。
- 明暗结构(对照概念图重新定的):主墙体改成中深板岩色(`wall` 0x767c9e,`wallDark`/`metal`/`deck` 同步加深),浅色只留给 `trim`/`wallLight` 的边缘和塔身;灯光改为太阳 2.8、半球光 1.2、补光 0.4、AO 0.65(明暗反差更大),明暗交界(`RAMP`)宽度减半,饱和度 1.14,最亮处混到纸白(概念图的亮面是纯白,雪的最亮档从 233 提到约 241 / 255);远景雾推远(`THREE.Fog` 50 / 700,原 24 / 420),中远景保留颜色和对比。全部可用网址参数回退:`&sun=2.35&hemi=1.65&fill=0.45&aoi=0.85&sat=1.07&fn=24&ff=420`。
- 悬崖着色器:雪盖只覆盖肩部(中等坡度),陡崖面保持干净岩石,不再滴出竖向白条。积雪垫(`snowPillow`)改为极坐标网格、桥墩脚积雪网格加密,外缘不再是格子阶梯;桥墩积雪的裙边会沿真实地面下沉(`snowDrift` 的 `floor` 回调),不再悬在陡坡上露出锯齿边;岩石脚下的积雪堆(`scatter.js` 的 `driftGeo`)在高差大的地方渐隐,不会顺着崖面拉出白竖条。阴影保持 PCFSoft(带半径的 PCF 会分成 9 个离散亮度台阶)。
- 峡谷两层岩壁之间的雪台现在平缓(平均坡度 ≤0.5,窄台把多余落差让给下层崖面),岩石遮罩用平滑过的坡度并减半抖动,不再出现大理石纹式的雪/岩细脉。已知未解决:台阶边缘与第二层崖脚处仍有少量细雪带。
